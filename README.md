# ONEMODE

**Fashion in Motion** — a front-end fashion marketplace portfolio project.

## Run locally

Open the `onemode` folder in VS Code and launch `index.html` with **Live Server**.

## Project structure

- `index.html` — home
- `shop.html` — category / brand / collection browsing
- `product.html` — product detail
- `brands.html` — brand index
- `collections.html` — curated collections
- `favourites.html` — saved products
- `checkout.html` — demo checkout
- `products.js` — single source of truth for product data
- `home.js` — home product feeds
- `shop.js` — filtering / sorting / shop rendering
- `product.js` — product gallery / cart / related products
- `cart.js` — cart state in localStorage
- `favourites.js` — favourites state in localStorage
- `script.js` — search / navigation / mobile menu / newsletter
- `style.css` — full site styling

## Notes

This is a **front-end portfolio demo**. Cart, favourites and demo checkout use browser `localStorage`; there is no backend, account system or real payment processing.
